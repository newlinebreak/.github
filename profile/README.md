# NewLine Break

**Hardware and software, built by one team.**

We design the board, write its firmware, and build the software it talks to.

| | |
|---|---|
| **Board design** | Schematic capture, multi-layer layout, DFM review, bring-up |
| **Firmware** | Bare-metal and RTOS, ARM and RISC-V, test fixtures |
| **Connected devices** | Provisioning, telemetry, over-the-air updates |
| **Web apps and APIs** | Web apps and internal tools, REST and GraphQL services, network servers in C++ |

## Client work

- **B/R Instrument**: a control system for laboratory distillation units. The work spans boards, firmware, a device server and the operator app.
- **PowerPool**: a solo mining pool, from stratum server to dashboard, live at [solo.powerpool.io](https://solo.powerpool.io). Also Zcash and failover for the main pool's stratum fleet.
